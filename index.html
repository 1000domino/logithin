POST 05 / BEFORE IMPLEMENTATION

•••

QUESTIONS BEFORE HOW

実装前に、
ここまで決める。

「何を載せる？」から始めず、前提から順に辿る。
今回の案件で、WHYとHOWの間に置いた6つの視点。

BEFORE WHY IMPLEMENT
01
PURPOSE なぜやる？ / 成果は？

非会員への認知拡大
参加者80人

↓
02
USER 誰に届ける？ / どんな状態？

既存会員＋非会員
特に非会員層

↓
03
CONTEXT / FLOW どこから来る？ / 何を知っている？

コラボメディアから流入

CONTEXT CHANGES CONTENT

ENTRY コラボメディア

イベント概要・日時・場所・料金などを知る

↓
ACTION 「詳しくはこちら」
↓
OWN LP すでに概要は知っている

だから、参加判断に必要な情報を優先する

PRIORITY

どんなプロがいる？

参加すると何が得られる？

申込後どうなる？

キャンセルできる？

↓
04
CONTENT 何を伝える？ / どの順番？

基本概要 / 参加価値
参加判断 / 申込・手続き

↓
05
REQUIREMENTS 何が必要？ / 成立条件は？

ページ内申込 / 支払
抽選・参加確定 / キャンセル

↓
06
IMPLEMENTATION どう作る？ / どこで公開？ / どう運用？

制作方法 / 公開環境
フォーム / 公開後の運用

AFTER

WHY → USER → CONTEXT / FLOW → CONTENT
→ REQUIREMENTS → IMPLEMENTATION

前提を辿ると、
「何を載せるか」と「どの順番で見せるか」まで変わる。
